# Skill Based Job Recommendation System

## Project Overview

The Skill Based Job Recommendation System is a Java Swing desktop application that helps users identify suitable job roles based on their skills and interests. The system analyzes user-selected skills and compares them with predefined job requirements to generate personalized job recommendations.

This project aims to bridge the gap between student skills and career opportunities by providing intelligent job suggestions through a user-friendly graphical interface.

---

## Problem Statement

Many students and fresh graduates are unsure which job roles best match their skills. This project helps users explore career options by analyzing their technical skills and recommending relevant job profiles.

## System Architecture

1. User enters skills through the GUI.
2. Skills are processed by the recommendation engine.
3. Weighted graph algorithm calculates skill relevance.
4. Matching job roles are identified.
5. Recommended jobs are displayed to the user.

---

## Algorithm Used

### Weighted Graph Algorithm

The project uses a weighted graph where:

- Skills are represented as nodes.
- Job roles are represented as nodes.
- Connections between skills and jobs have weights.
- Higher weights indicate stronger relevance.

The algorithm calculates the total matching score between user skills and available job roles and recommends jobs with the highest scores.
